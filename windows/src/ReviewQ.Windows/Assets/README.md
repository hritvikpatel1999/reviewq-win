# Companion artwork

The Edge, Scout, and GitHub Copilot PNGs are cropped from the icon reference
supplied by the repository owner for the Windows visual refresh. Only the
individual icons are included, not the surrounding screenshot. Background pixels
connected to the crop edges are transparent. These are app-identification assets,
not ReviewQ branding.

Artwork renders at 16 DIPs in queue actions (18 on hover) and at 32 DIPs in
setup companion rows. High-contrast mode uses the existing foreground-bound
vector symbols instead.
